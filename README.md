# Аналіз асортименту та попиту на товари

## Опис проєкту
Навчальний проєкт з аналізу даних, присвячений дослідженню товарного асортименту, обсягів продажів, категорій і брендів. Аналіз виконано за допомогою Python, а результати представлено у вигляді графіків та інтерактивної панелі Tableau.

## Мета
Дослідити структуру асортименту та характеристики продажів, визначити популярні товари й категорії, розглянути продажі у часовому вимірі та візуально представити результати.

## Дані
Для аналізу використовуються три CSV-файли:
- `products.csv` — характеристики товарів, зокрема назва, категорія, бренд і ціни;
- `sales.csv` — записи продажів, дата, кількість, знижка та спосіб оплати;
- `categories.csv` — довідник категорій та товарних груп.

## Інструменти
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Tableau Public

## Структура проєкту
- `analysis_assortment_demand.ipynb` — ноутбук із завантаженням, перевіркою, очищенням, об'єднанням даних, аналізом, графіками та експортом результатів.
- `Аналіз продажів.twb` — файл Tableau Workbook із п'ятьма аркушами та Dashboard.
- `products.csv`, `sales.csv`, `categories.csv` — вихідні таблиці.
- `analysis_dataset.csv` — об'єднаний набір даних, який експортується ноутбуком і використовується для подальшого аналізу/підключення в Tableau.

## Етапи аналізу в ноутбуці
1. Завантаження вихідних таблиць та огляд їх структури.
2. Перевірка типів даних, пропусків і дублікатів.
3. Очищення та підготовка таблиць.
4. Об'єднання даних про продажі, товари й категорії.
5. Формування аналітичних показників, зокрема розрахунок виручки з урахуванням роздрібної ціни та знижки.
6. Ранжування товарів за кількістю продажів.
7. Групування та порівняння категорій.
8. Формування зведених таблиць.
9. Візуальний аналіз і кореляційне дослідження.
10. Експорт об'єднаного набору даних.

## Візуалізації у Python
У ноутбуці передбачені такі графіки:
- топ товарів за кількістю продажів;
- виручка за категоріями;
- розподіл кількості реалізованих одиниць;
- взаємозв'язок ціни та обсягу продажів;
- динаміка продажів у часі;
- кореляційна матриця числових показників.

## Tableau Dashboard
Файл `Аналіз продажів.twb` містить Dashboard **«АНАЛІЗ АСОРТИМЕНТУ ТА ПОПИТУ»** та п'ять аркушів:
- **Топ-10 товарів** — рейтинг товарів за кількістю реалізованих одиниць;
- **Виручка за категоріями** — порівняння категорій за виручкою;
- **Динаміка продажів** — зміни обсягу продажів у часі;
- **Продажі за брендами** — порівняння брендів;
- **Ціна та кількість продажів** — діаграма розсіювання для дослідження співвідношення ціни й продажів.

## Як запустити ноутбук
1. Завантажте репозиторій або скопіюйте файли проєкту в одну папку.
2. Переконайтеся, що три вихідні CSV-файли (`products.csv`, `sales.csv`, `categories.csv`) розташовані поруч із ноутбуком.
3. Відкрийте ноутбук у Jupyter Notebook або Google Colab.
4. За потреби встановіть бібліотеки:
   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
5. Виконуйте комірки ноутбука послідовно, від початку до кінця.
6. Після виконання ноутбук створить файл `analysis_dataset.csv`.

## Як відкрити Tableau Workbook
1. Відкрийте Tableau Public Desktop або Tableau Desktop.
2. Відкрийте файл `Аналіз продажів.twb`.
3. Якщо Tableau запитує шлях до джерела даних, вкажіть актуальний файл `analysis_dataset.csv` або відповідне джерело, використане під час створення Workbook.
4. Перевірте аркуші та Dashboard. За потреби оновіть підключення до даних.

## Примітка
Файли даних мають бути доступні за шляхами, які використовуються у ноутбуці або Tableau Workbook. Якщо структура папок чи назви файлів змінюються, необхідно відповідно оновити шляхи до джерел даних.

Проєкт має навчальний характер і демонструє застосування Python та Tableau для аналізу товарного асортименту й продажів.
